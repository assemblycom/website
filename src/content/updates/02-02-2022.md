## API Beta

After half a year of development we're preparing for the initial release of Portal API and Zapier automations. If you'd like to receive early access, please [fill out this short form](https://portal9.typeform.com/to/cf552acU?ref=copilot-updates.ghost.io) and join the #API channel [in our Slack community](https://join.slack.com/t/portalcommunity/shared_invite/zt-q6stzfgx-vBf7LBtbKFv63W4n_Otx4w?ref=copilot-updates.ghost.io).

## Improvements &amp; Updates

- Improved the performance of the Messaging module. Scrolling through conversations and selecting a channel is now 60% faster on average.
- Improved the initial load speed every portal app.
- Updated the *invite team member* modal to make it more clear how per-seat pricing works.
- Fixed a bug that prevented column sorting from working.
- Fixed a bug that resulted in the original module names to be used on the client details page (instead of custom names).
